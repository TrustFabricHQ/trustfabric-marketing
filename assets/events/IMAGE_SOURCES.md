# Event imagery: sources, rights and status

This is the single reference for every external image considered for the Events pages.
Nothing from the lists below has been downloaded into the project or shown on the site yet.
Each row waits for approval, and for permission where the rights column says so.

Rules for adding any image to the site:

- Use an image only for the event it belongs to, and say the year when it is from a past edition.
- Never use a past-year photograph as if it showed the 2026 or 2027 event.
- Never imply TrustFabric exhibited somewhere using a generic event photograph.
- Store the file in `assets/events/`, never hotlink, and add its row to this file with the source URL and who gave permission.
- If there is no official or permitted image, the page stays typography-led.

Checked on 14 November 2026.

## Recommendation

1. Use official **logos** only, and only where use is clear: Tech Expo Gujarat now, Bengaluru Tech Summit after confirming with its secretariat, DSCI and RSAC after permission.
2. Use **no event photographs** from any organiser until permission is given and the edition is confirmed. Every photograph found is under "All Rights Reserved" with no terms, and several are undated or from earlier editions.
3. Add TrustFabric's **own photographs** to the journal after each event. The page is built so they drop straight in (see `assets/events-data.js`).

Open question: what is TrustFabric's role at each event (exhibitor, sponsor, speaker, visitor)? It decides what each organiser will let us use.
